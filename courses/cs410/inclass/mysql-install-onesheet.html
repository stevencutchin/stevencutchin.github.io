Why Workbench 8.0.47 and not 26.7. Oracle released Workbench 26.7 on 10 September 2026, a rebuild on MySQL Shell and Electron that obsoletes the 8.0 line. Its published feature set covers SQL editing, notebooks, Visual Explain, and administration — it does not yet include Database Design and Modeling. EER diagramming and reverse engineering are required by HW2 Part 2 and the integration capstone, so the course pins the final 8.0 release, still available from the MySQL archives. Workbench 8.0.47 connects to an 8.4 LTS server for SQL and reverse engineering; some administration panels may warn about the server version, and this course does not use them.

Install order and settings

  1. Run vc_redist.x64.exe. Reboot only if it asks.
  2. Run mysql-8.4.11-winx64.msi. MySQL Configurator launches on its own when the MSI finishes.
  3. In Configurator accept Development Computer, port 3306, and Use Strong Password Encryption. Keep Start at System Startup checked and the service name MySQL84. Set the root password from the Canvas setup page.
  4. Run mysql-workbench-community-8.0.47-winx64.msi, launch it, and confirm the localhost:3306 connection opens.
  5. Unzip each sample database and load it: mysql -u root -p < sakila-schema.sql then mysql -u root -p < sakila-data.sql.
  6. Verify the install: SELECT COUNT(*) FROM sakila.film; returns 1000.

Lab machines. Image CCP-243 from a prefetched bundle rather than downloading live — thirty seats each pulling 415 MB will saturate the room. Run fetch-mysql-win.sh to stage the folder, copy it to a USB drive or share, then run verify-bundle.cmd on the target machine to confirm nothing was corrupted in transit.

Reverification. Every checksum here was read from the official MySQL download pages on 1 October 2026. MySQL ships an 8.4 patch roughly quarterly; when 8.4.12 appears these filenames and checksums change together, and both this sheet and the script's package table need updating.
